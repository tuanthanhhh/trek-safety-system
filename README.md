# Outdoor Safety Tracker System
> A Personal Outdoor Safety Tracker designed for trekking and remote activities, featuring fall detection, GPS tracking, environmental sensing, and LoRa-based emergency communication for real-time user monitoring.

## 📌 Overview
This project implements a handheld embedded system that enhances user safety during outdoor activities such as trekking, hiking, or exploration in remote areas.

The system continuously monitors user status and environment, detects abnormal conditions (e.g., fall or unconsciousness), and transmits alerts to a central monitoring station via LoRa communication.

## 🎯 Key Features
- Fall detection
- Lora Communication
- GPS Tracking
- Environmental Monitoring
- Digital Compass
- Emergency SOS
